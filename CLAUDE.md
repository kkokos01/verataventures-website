# Project instructions

## Design system

Always read `BRAND.md` and `DESIGN.md` before making visual, UI, messaging, or
artifact decisions for Verata Ventures. Consume exact values from
`brand/tokens.json` or `brand/tokens.css`; do not sample colors from screenshots.

Do not deviate from the approved font roles, color semantics, logo behavior, mode
strategy, voice, or audience posture without explicit user approval. In review or QA,
flag any implementation that conflicts with the brand guide.

The logo geometry is locked. Reuse the masters in `brand/assets/`; never redraw the
mark from screenshots or approximate it with SVG strokes. Website copies in
`public/brand/` must remain byte-identical to the canonical masters.

For AI-created assets, begin with `brand/ai-brief.md` and append the relevant
artifact-specific block.
