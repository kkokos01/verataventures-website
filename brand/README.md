# Verata Ventures brand system

- `../BRAND.md`: complete human-facing brand guide.
- `../DESIGN.md`: concise implementation contract for designers and developers.
- `tokens.json`: machine-readable design tokens.
- `tokens.css`: CSS custom properties for light and dark modes.
- `ai-brief.md`: reusable prompt contract and artifact add-ons.
- `brand-guide.html`: visual specimen using the approved fonts and colors.
- `logo-proof.html`: master-mark proof with formal, expressive, and reduction tests.
- `logo-proof.png`: review image generated from the proof sheet.
- `website-preview.png`: desktop preview of the first production website application.
- `assets/`: locked, canonical V mark variants and exact construction reference.
- `../public/brand/`: byte-identical copies served by the production website.

The system name is **Live Mineral / Humanist Intelligence**. Light mode is the
default. Newsreader is the public editorial voice, Instrument Sans is the operating
voice, and Geist Mono is restricted to metadata and evidence.

The logo geometry is locked as of 22 July 2026. Always reuse the canonical SVG;
do not reconstruct it from screenshots or approximate it with stroked lines.
